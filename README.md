# Electric-Vehicle-PowerBI-Dashboard
Interactive Power BI dashboard analyzing Electric Vehicle population data (US).

Project Overview

This Power BI dashboard analyzes Electric Vehicle (EV) population data and provides insights into EV adoption trends, vehicle types, manufacturers, and geographical distribution.

KPIs
Total Vehicles
Average Electric Range
Total BEV Vehicles
Total PHEV Vehicles
BEV Percentage
PHEV Percentage

Visualizations
Vehicles by Model Year
Vehicles by State (Map)
Top 10 Vehicles by Make
CAFV Eligibility
Top 10 Vehicles by Model

Tools Used
Power BI
Excel
CSV Dataset
